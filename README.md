#  ToDoList Web App

ToDoList Web App is a simple and interactive task management application that helps users add, manage, and delete their daily tasks in an easy and organized way.

##  Features
- Add new tasks easily  
- Delete completed tasks  
- Simple and clean user interface  
- Fully responsive design  
- Smooth and interactive experience  

##  Technologies Used
- HTML  
- CSS  
- JavaScript  

##  Project Overview
This project is built to practice core front-end development skills using HTML, CSS, and JavaScript. It focuses on DOM manipulation and user interaction to create a functional and easy-to-use to-do list application.

##  Purpose
The main goal of this project is to improve JavaScript skills, especially working with DOM events and creating real-world interactive web applications.
